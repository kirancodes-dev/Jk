- **Citizen flow** (`kCitizenFlowKeys` in `frontend/lib/core/localization/citizen_flow_keys.dart`): every string a citizen sees on login, the dashboard, the 5-step report form, the submission confirmation, My Challenges and the status tracker (lifecycle, status, priority and escalation-tier labels), notifications, and My Data & Privacy.
- **Core flow** (`kCoreCitizenFlowKeys`): the 73-key minimum every tribal language covers: sign in, home, the five report steps, the main statuses, notifications and the privacy entry points.
- Officer, university, industry and admin screens are not translated into tribal languages; they show Hindi.

`frontend/test/tribal_language_test.dart` fails CI if any citizen-flow key is missing in Santali, any core key is missing in the other four languages, a translation drops a `{placeholder}`, a Santali string is not in Ol Chiki, or any locale throws while resolving a string.

## How drafts are shown
- **Fallback chain:** requested language → Hindi → English → key. Interpolated strings (`{count} unread updates`), lifecycle stages and status labels follow the same chain.
- **Pilot and demo builds** show the drafts, with an in-app note on the language picker that tribal text is a draft awaiting native-speaker review.
- **Production builds must hide unreviewed drafts** until sign-off: `flutter build web --dart-define=HIDE_UNREVIEWED_TRANSLATIONS=true`. Each unreviewed key then shows Hindi.
- **Fonts:** Noto Sans Ol Chiki (Santali) and Noto Sans Warang Citi (Ho's name in the language picker) are bundled under the SIL Open Font License 1.1 (`frontend/assets/fonts/`, licences on the app's licence page). Text renders on devices and browsers that lack these scripts, without fetching fonts from the internet.

**P0 strings (review first).** These carry consent, data-rights and privacy wording under the DPDP Act 2023, so a mistranslation changes what a citizen agrees to: `declaration_text`, `data_sharing_consent_label`, `data_sharing_public_aggregated`, `data_sharing_authorized_research_only`, `data_sharing_government_only`, `submit_anonymously_subtitle`, `report_step2_sub`, `request_erasure_warning`, `erasure_confirmation_label`, `request_erasure_desc`, `export_my_data_desc`, `correct_my_data_desc`, `dpdp_subtitle`, `privacy_notice_title`, `your_data_rights_title`. Only Santali drafts all of them; the other four languages draft `your_data_rights_title` and show the rest in Hindi.

### Sign-off process
1. A native speaker (ideally two per language, e.g. via the Department of Tribal and Regional Languages, Ranchi University) works through the sheet, P0 first, and fills `corrected_text`, `reviewer` and `review_date`.
2. A developer applies the corrections in `frontend/lib/core/localization/app_localizations.dart` and adds each signed-off key to `kNativeReviewedKeys` in `translation_review.dart`.
3. Re-run `python scripts/translation_coverage.py --markdown --sheets docs/translations` and update the table above.
4. A language may be called "complete" only when every citizen-flow key is present **and** reviewed.

## Open questions for native speakers
- **Ho script.** The drafts use Devanagari; the language picker shows Ho's name in Warang Citi (`𑢹𑣉𑣉 𑣎𑣋𑣜`). Should the UI text also be in Warang Citi?
- **Kurukh script.** Devanagari is used. Tolong Siki is not yet in Unicode, so it cannot be supported until it is encoded.
- **Santali numerals.** Step titles use Ol Chiki digits (`ᱫᱷᱟᱯ ᱑/᱕`), while counts filled in at runtime use 0–9. Is the mix acceptable?
- **Terminology.** Loanword vs native coinage for *university*, *data*, *password*, *portal*, and the words chosen for *category* (`ᱛᱷᱚᱠ`), *right* (`ᱦᱚᱠ`) and *status* (`ᱦᱟᱹᱞᱚᱛ`).

## Known gap in the source strings
The recent report-form copy edit simplified several English labels (e.g. `attach_evidence_label`, `geo_coordinates_label`, `canonical_domain_label`, `ground_description_label`, `submit_to_government_pipeline`), but their Hindi strings still carry the older wording. The tribal drafts follow the new English. The Hindi strings should be refreshed so the fallback language says the same thing.
