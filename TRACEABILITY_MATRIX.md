**Problem Statement ID**: 26043
**Title**: A digital platform to crowdsource societal challenges and facilitate collaborative problem solving through universities and industry partnerships.
**Organization**: Government of Jharkhand — Department of Higher & Technical Education

This document is generated against the **actual codebase**, not aspirational design.
Every backend file, Flutter screen, and test reference below is verified to exist by
`scripts/verify_traceability.py`, which runs in CI on every push — if a cited path or
test goes stale, the build fails instead of the document silently drifting from reality.

**Status legend**:
- **Implemented** — working end-to-end, covered by an automated test.
- **Partial** — some but not all of the requirement is real (see notes).
- **Simulated** — the code path exists and is exercised, but a component it depends on
  is a stand-in (documented as such in the code/API response), not a live external system.
- **Planned** — not yet built; listed here so scope stays honest rather than silently dropped.

## Known Gaps (tracked, not hidden)

1. **SMS/WhatsApp notification providers are simulated** — see Module 7 above. This is stated in the code (`provider = "SIMULATED_SMS"`) and should also be stated in any user-facing copy that mentions SMS/WhatsApp.
2. **CSR fund release never claims a real payment transfer** — `finance_integration_service.py` is a governance stub that returns `NOT_CONFIGURED` deterministically; wiring a real payment/finance backend is future work, not simulated success today.
3. **Multilingual embeddings-based deduplication is optional and off by default** — `deduplication_service.py`'s rule-based bag-of-words similarity remains the always-on baseline; a `sentence-transformers`-backed similarity path (`embedding_service.py`) only activates when `AI_EMBEDDINGS_ENABLED=true` AND the optional dependency is installed (see `backend/requirements-optional.txt`). Domain classification (`classification_service.py`) is not yet wired to embeddings and remains rule-based only.
4. **Hindi localization does not yet cover every screen in the app** — the citizen/submitter flow and the two originally-partial common screens are fully converted (`frontend/lib/core/localization/app_localizations.dart`); university/industry/admin-only screens and the university-role login sub-flow (`university_selection_screen.dart`, `university_role_selection_screen.dart`) are not yet converted.

## How this document stays honest

Run `python scripts/verify_traceability.py` locally or let CI run it — it parses every
backtick-quoted path citation rooted at `backend/`, `frontend/`, `tests/`, `scripts/`,
`docs/`, or `alembic/` in this file, confirms the path exists, and for a
`path/to/file.py::test_name`-style citation also confirms that test function is actually
defined in that file. A stale citation fails the build the same way a broken test would.
